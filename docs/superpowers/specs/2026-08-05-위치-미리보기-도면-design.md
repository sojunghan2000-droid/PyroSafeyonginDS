# 장비 등록 — '기존 위치 선택' 도면 미리보기 (읽기전용) · 설계

- 날짜: 2026-08-05
- 대상: `lib/inspection_dialog.py` 장비 등록 다이얼로그 "기존 위치 선택" 모드
- 상태: 설계 확정 (브레인스토밍 완료)

## 배경 / 문제

신규 장비 등록 다이얼로그의 **위치 지정** 은 두 모드다.
- **기존 위치 선택**: `층`+`위치(spot)` 드롭다운만 있고 **도면이 없다** → 고른 spot이 도면상 어디인지 확인 불가.
- **신규 위치 만들기**: 이미 클릭 가능한 도면(`_eq_new_spot_map`)이 있다.

드롭다운으로 spot을 고를 때 "이 위치가 도면상 어디였더라?"를 확인할 수단이 없는 것이 약점이다.

## 목표

"기존 위치 선택" 모드에, 선택한 spot의 위치를 도면 위 마커로 보여주는 **읽기전용 미리보기**를 추가한다. **접을 수 있게(기본 접힘)** 한다.

## 결정 사항 (브레인스토밍)

1. **읽기전용 미리보기** — 드롭다운이 입력 수단 그대로. 도면은 선택된 spot 위치에 마커를 찍어 확인만. (클릭 선택 아님)
2. **표시 범위** — 선택 spot은 강조, 같은 층의 다른 spot·기존 장비는 옅은 회색으로 함께(맥락). 기존 픽커와 톤 일치.
3. **기본 접힘** — `st.expander(expanded=False)`. 등록 다이얼로그가 이미 길어 세로 공간을 아낀다. (기존 '전 층 도면 미니그리드'가 기본 접힘으로 바뀐 것과 일치)
4. **범위** — "기존 위치 선택" 모드에만. "신규 위치 만들기"는 변경 없음.

## 설계

### 새 함수 `_spot_preview_map(sel_spot, all_eq, all_spots)`

- 위치: `lib/inspection_dialog.py`, `_location_map_picker`([lib/inspection_dialog.py:602](../../../lib/inspection_dialog.py)) 근처.
- 시그니처: `def _spot_preview_map(sel_spot) -> None`
  - `sel_spot`: 선택된 `FloorSpot`(속성 `floor, room_name, x_pct, y_pct, spot_id`).
  - 필요한 데이터는 **함수 내부에서 로드**: `data.load_spots(sel_spot.floor)`, `data.load_equipment()`(해당 층으로 필터). (장비 다이얼로그 스코프엔 `all_spots`만 있고 `all_eq`는 없으므로, 미정의 변수 전달을 피하고 자기완결로 둔다. `load_*`는 캐시됨.)
- 동작(읽기전용 정적 렌더):
  1. `floor = sel_spot.floor`. `assets/floors/{floor}.png` 없으면 `st.warning("{floor} 도면 이미지가 없습니다.")` 후 반환.
  2. 좌표 매핑은 픽커와 동일: `x = x_pct/100*FIG_W`, `y = FIG_H - y_pct/100*FIG_H` (`FIG_W, FIG_H = 2978, 2105`).
  3. **맥락(옅은 회색)**: 같은 층의 다른 spot(선택 제외)과 기존 장비를 회색(`#94A3B8`) 마커(spot=◇ diamond, 장비=● circle)로. hover=room_name/장비명.
  4. **선택 spot 강조**: 파란 별(symbol=`star`, color=`#2563EB`, size≈22, 흰 테두리)로 `sel_spot` 위치에 1개. hover=`{room_name} ({spot_id})`.
  5. 레이아웃: 픽커와 동일 축설정(`visible=False`, `scaleanchor`), `height≈360`, `on_select` 없음, 잠금토글 없음, `plotly_config()`([lib/floor_widget](../../../lib/floor_widget.py)) 재사용.
- **중복 최소화**: "이미지→base64 data URI" 변환만 작은 헬퍼 `_floor_image_uri(floor) -> str | None`로 추출해 픽커/신규픽커/미리보기가 공유(선택 리팩터, 범위 내 3곳). 마커 로직은 미리보기용으로 별도(정적).

### 배치 — "기존 위치 선택" 분기

[lib/inspection_dialog.py:1908-1940](../../../lib/inspection_dialog.py) 의 드롭다운(c3/c4) 아래, `sel_spot`이 있을 때만:

```python
if sel_spot is not None:
    with st.expander("🗺️ 도면에서 위치 확인", expanded=False):
        _spot_preview_map(sel_spot)
```

- 그 층에 spot이 없어 `sel_spot`이 `None`이면 도면을 그리지 않는다(기존 안내 문구 유지).
- 드롭다운으로 spot을 바꾸면 rerun으로 미리보기도 즉시 갱신.

### 변경 없음

- "신규 위치 만들기" 모드의 클릭 도면(`_eq_new_spot_map`)·좌표 픽업 로직 — 그대로.
- `_location_map_picker`(오동작·신규 위치 점검 픽커) — 그대로(선택 리팩터로 `_floor_image_uri`만 공유 시 내부 한 줄 치환).
- DB·스키마·저장 로직 — 변경 없음(읽기전용).

## 엣지 케이스

- 층 도면 이미지 없음 → 안내 문구 후 반환(픽커와 동일 UX).
- `sel_spot` 좌표가 도면 밖(비정상 x/y) → 마커가 가장자리에 찍힘(치명적이지 않음). 별도 처리 없음.
- 같은 층에 다른 spot/장비가 없으면 → 선택 spot 별 마커만 표시.
